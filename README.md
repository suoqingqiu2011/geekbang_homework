# AI Agent 全栈工程师训练营的作业交付
## Navigation
### [ch1：第一章 llm gateway 的作业练习](ch1/llm-gateway/)
实现一个自建 **LLM 网关（llm-gateway）**，基于 **Python + FastAPI**，对外暴露 **OpenAI 兼容的 HTTP / SSE 接口**，通过 Adapter 模式统一接入 **DeepSeek、OpenAI、Kimi、Qwen、Anthropic、Ollama** 六家供应商。网关贯穿完整调用链路：Bearer 鉴权（支持 Key 绑定 user / project 与硬性预算）→ 分层 Token Bucket 限流（per-model / endpoint / project / user）→ 请求校验与 Prompt 注入启发式检测 → Trace 固化 → Jinja2 模板渲染（多版本，支持 HTTP / Web UI / CLI 管理）→ 按成本、thinking 能力、routing_weight、上下文窗口与预算动态路由 → 重试 / fallback / 跨 worker 持久化熔断 → OpenAI-compatible / Anthropic 适配器 → 结构化输出能力降级、JSON Schema 本地校验与自动修复（含流式 `validation` 事件、`buffer_until_valid` 缓冲模式）→ 按 prompt / completion 分价计费，并以 `billing_id` 保证 SQLite 用量 / 成本 / Trace / 日报聚合的幂等写入；同时提供配置原子热更新、`/healthz` `/readyz` `/metrics`、`/v1/admin` 只读查询与运维 CLI，SSE 流式支持 TTFT 统计、`partial_failed` 标记与客户端断连取消。配套 18 个全 mock 测试文件，覆盖 E2E 与单元场景，无需真实 Provider Key 或外网。

### [ch2：第二章转账功能的作业练习](ch2/tool_governance/)
实现一个 **工具治理演示框架（tool_governance）**，模拟 AI Agent 调用工具时的完整治理链路：**参数校验 → 权限判断 → 业务预检 → 人工审批 → 超时处理 → 结果脱敏 → 审计追踪**。框架内置 `get_order`、`create_refund`、`run_shell` 与新增 `transfer` 四个示例工具，覆盖 Pydantic 严格类型 / 正则 / 范围校验防注入、9 级固定优先级权限状态机（deny → plan → whitelist → RBAC → 业务预检 → 一次性审批 → bypass → allow → default）、基于 SHA-256 规范化参数摘要的一次性内容绑定审批（校验用户 / 租户 / 工具 / 参数，带 TTL、`used` 消费标记与可注入时钟）、`idempotency_key` 幂等去重（`DUPLICATE_REQUEST`）、`asyncio.timeout` 超时兜底（幂等读可重试，非幂等写返回 `TIMEOUT_UNKNOWN` 且不改余额）、敏感字段 / 邮箱 / 账户号递归脱敏，以及 decision / execution 两阶段审计（`trace_id`、`decision`、`code`、`latency_ms`）。配套 14 项验收测试，并支持可选的 `--agent` 真实模型自然语言闭环（DeepSeek）。

### [ch3：第三章 guarded coding harness 的作业练习](ch3/guarded_coding_harness/)
实现一个 **受控编码执行框架（guarded_coding_harness）**，基于 **Python + smolagents 的 `ToolCallingAgent`**，在不改写内核源码的前提下仅覆写 `process_tool_calls` 一处拦截缝，为自主 Coding Agent 增加一层可恢复的治理层。框架内置 10 个工具（`list_files`、`search_code`、`read_file`、`inspect_workspace`、`write_file`、`apply_patch`、`run_test`、`record_evidence`、`update_plan`、`final_answer`），并贯穿完整调用链路：执行前统一门禁（参数校验 → 沙箱前置检查 → 重复写入 / 重复动作 → 预算 → 写审批，批次预占且任一请求被拒即整批中止）、沙箱边界（路径三区与 `realpath` 真实落点校验、敏感目录与密钥文件硬阻断、命令白名单与元字符检查、超时与取消、Windows Job Object / POSIX `killpg` 真实终止进程组、最小环境变量、输出尾部裁剪 + 全量日志）、写入与测试运行的意图登记及 `EXECUTED / NOT_EXECUTED / UNCERTAIN` 三态对账（`NOT_EXECUTED` 释放签名允许合法重试，重复写入拒绝并返回首次结果回执）、审批的签名 + 工区指纹 + TTL + actor 绑定与拒绝 / 过期 / 指纹失效处理、按 run 隔离并带校验和的原子 Checkpoint 跨进程恢复（暂停可续、取消终态、阻断标记不可洗白；按阻断 → 进程退出未确认 → 未销记测试意图 → 终态 → 指纹变化 → 待对账 → 预算的固定优先级判定）、只认当前指纹下最新测试证据的完成契约，以及 append-only 哈希链审计（`audit.jsonl.head` 锚点检测尾部截断与清空，支持按 `run_id` / `tool_call_id` 还原决策链）；配套 6 个测试文件，以及离线、真实模型、真实模型完整审批三套演示脚本，交付记录落盘于 `ch3/artifacts`。

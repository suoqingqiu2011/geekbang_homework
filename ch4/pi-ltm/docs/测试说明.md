# 会话测试说明

## 测试入口

`tests/auth/test_session.py`（会话测试已从 `tests/test_session.py` 迁移到此，旧入口已删除）

## 运行命令

```bash
python -m unittest tests.auth.test_session -v
```

## 前置条件

- 工作目录：`pi-ltm` 项目根（模块路径为 `tests.auth.*`，`tests/auth/__init__.py` 已提供包标记）
- 单用例：`python -m unittest tests.auth.test_session.LoginSessionTest.test_login_success_returns_token -v`
- `login_demo` 位于 `../login_demo`（可用 `LOGIN_DEMO_ROOT` 覆盖）
- `login_demo` 已执行 `npm install`；`dist/server.js` 缺失时自动 `npm run build`
- 端口 3001 空闲；测试自行拉起并回收 `node dist/server.js`

## 覆盖范围

1. 登录成功返回 `demo-token.` 前缀令牌，用户 `u_1001` / `member`
2. 密码错误返回 401 `Invalid password`
3. 缺少字段返回 400
4. 无令牌访问 `/api/profile` 返回 401 `Missing bearer token`
5. 携带令牌访问 `/api/profile` 返回 200，`currentUser.userId` 为 `u_1002`

## 现场文件

失败时服务端输出保存在 `tests/.artifacts/server.log`（测试运行时自动创建，属本地临时产物，勿提交）。
